# Brand assets

`volksbank.svg` uses the Volksbanken Raiffeisenbanken standalone mark geometry
published by BVR via Wikimedia Commons under CC BY-SA 4.0. The paths were
cleaned for web use and the colors updated to the current published brand values
VR blue `#0066b3` and VR orange `#ff6600`. This is an adapted work; the asset
remains under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
and is not covered by the repository's MIT license.

Source: https://commons.wikimedia.org/wiki/File:Volksbank_Logo.svg

Brand guide: https://www.vvr-bank.de/meine-bank/pressebereich.html

Volksbanken Raiffeisenbanken is a protected trademark of its owner. The mark is
used only to identify a connected data source; finsight is not endorsed by or
affiliated with Volksbanken Raiffeisenbanken.

## Provider artwork

The following local assets identify an account provider. They are not covered
by the repository's MIT license, and their use does not imply a partnership or
endorsement.

| Asset | Artwork source | Asset terms |
| --- | --- | --- |
| `coinbase.svg` | [Official Coinbase press logo pack](https://www.coinbase.com/press) | The file crops the unchanged blue `C` glyph from Coinbase's official wordmark. Coinbase's brand guidelines and trademark rights apply. |
| `trading212.svg` | [Trading 212 at SVG Repo](https://www.svgrepo.com/svg/331610/trading-212) | The source page marks this particular SVG as CC0. Trading 212's name and mark remain protected trademarks. |

The Coinbase artwork is kept in its published blue and is not rotated,
distorted or given additional effects. The Trading 212 geometry and colors are
stored unchanged apart from removing generator metadata and fixed pixel
dimensions that are unnecessary for responsive rendering.

## Reviewed brands without bundled artwork

The remaining bank identities use Finsight's neutral initials badge. Their
official media downloads do not include a sufficiently broad redistribution
permission for bundling the marks in this MIT-licensed repository, or no clear
public terms could be located. A press download alone is not treated as an
application-asset license.

| Brand | Reviewed official source | Result |
| --- | --- | --- |
| Postbank | https://brandportal.postbank.de/de/nutzungsbedingungen | Portal use is restricted to employees and commissioned partners. |
| DKB | https://www.dkb.de/presse/mediathek | Images are offered for editorial use by journalists with attribution. |
| ING | https://www.ing.de/dokumente/regeln_zur_logo-verwendung/ | Published rules address ING partners and partner advertising. |
| Santander | https://www.santander.de/unternehmen/presse/ | No general application-redistribution permission was found. |
| Targobank | https://www.targobank.de/de/ueber-uns/newsroom/ | The official newsroom provides press artwork but no broad software redistribution grant. |
| Consorsbank | https://www.consorsbank.de/web/Ueber-uns/Presse | The official media area provides press material but no broad software redistribution grant. |
| Comdirect | https://www.comdirect.de/cms/ueberuns/de/presse/presse-download.html | The official press download has no broad software redistribution grant. |
| GLS Bank | https://www.gls.de/gls-bank/service/fragen-antworten/ueber-die-gls-bank-und-ihre-arbeit/verlinktes-gls-logo-zur-einbindung-auf-ihrer-website/ | GLS explicitly requires prior written permission. |
| Tomorrow | https://www.tomorrow.one/en-EU/press/ | The media center has no broad software redistribution grant. |

This review is intentionally conservative and is not legal advice. If a bank
grants suitable written permission later, its unmodified official SVG can be
added to the registry without changing stored connections.
